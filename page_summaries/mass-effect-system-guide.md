This page is a gameplay reference index, not lore prose. It lists every star system in Mass Effect by cluster (Argos Rho, Armstrong Nebula, Artemis Tau, Attican Beta, Exodus Cluster, Gemini Sigma, Hades Gamma, Hawking Eta, Horse Head Nebula, Kepler Verge, Local Cluster, Maroon Sea, Pangaea Expanse, Sentry Omega, Serpent Nebula, Styx Theta, and the Voyager Cluster), noting how each system is unlocked and which missions and assignments (largely UNC assignments and mineral surveys) it contains.
