PC Tweaks (Mass Effect 2) was a wiki reference guide for modifying the PC version of Mass Effect 2, which was based on Unreal Engine 3 and could be tweaked much like the first game. Unlike Mass Effect, Mass Effect 2 locked its in-game console more thoroughly, so most effects and commands had to be enabled by editing configuration files or patching game binaries.

The guide advised backing up career saves (stored under Documents\BioWare\Mass Effect 2\Save in folders named by first name, psych profile, class, and creation date) and the Player1.prf profile file that held achievements and bonus power unlocks. It warned that some tweaks required editing DLC files, which could trigger an "not authorized" error needing DLL patching, though Legendary Edition no longer performed DLC integrity checks. It described three ways to enable the console: using a DLL patching tool that also unlocked the in-engine console, running a program to patch SFXGame.pcc, or manually hex-editing MassEffect2.exe at a specific offset (a method broken by the newest patch). For Legendary Edition the only method given was installing the binkw64 proxy, available through the ME3Tweaks Mod Manager. Once enabled, the tilde key opened a three-quarter-screen console and Tab opened a single-line console.
