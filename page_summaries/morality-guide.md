This is a walkthrough reference page listing the exact conversation and action triggers that award Paragon and Renegade points throughout the first Mass Effect. It gives starting Paragon/Renegade totals for each background and psych-profile combination (Spacer/War Hero grants 20 Paragon, Earthborn/Ruthless grants 20 Renegade, and so on), then works through the game area by area: the Eden Prime prologue, Citadel: Expose Saren, the various Citadel assignments, Noveria (Geth Interest, Lorik Qui'in, Matriarch Benezia, Rift Station and the Rachni Queen), Feros and the Thorian, Virmire (Wrex and the genophage), and beyond. Each entry names the specific dialogue line, the Charm or Intimidate rank required, and the point value granted, with running totals and "freebie" skill points per section. The page is a data table with no narrative prose.
