This is a technical guide, not a lore page. It documents how PC players can mod, tweak or cheat Mass Effect 3, which runs on Unreal Engine 3. It covers backing up save careers and LocalProfile.sav, editing tools (Wenchy Coalesced Utility, Mass Effect 3 Mod Manager / ME3Tweaks Mod Manager, Gibbed extractors, ME3Explorer), the locations of Coalesced.bin and DLC .sfar configuration files, and a warning that multiplayer-affecting changes can result in a ban. It then lists assorted Coalesced.bin tweaks (store mark-up removal, unlocking stores and bonus powers, editing War Assets, weight-penalty removal, exploration and Reaper-chase values, FOV, bloom), instructions for enabling and using the in-game console with a level-name list, keybind and FlyCam examples, and sections on editing powers and individual weapons. No in-universe narrative content.
