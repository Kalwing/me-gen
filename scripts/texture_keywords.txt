# World-texture keyword cloud for codex/culture.md, codex/social.md, codex/everyday.md
# coverage. One keyword/phrase per line; '#' starts a comment; blank lines ignored.
# Single words match whole-word only (no accidental substring hits like "art" inside
# "Arterius"). Append '*' to a word to opt into prefix matching for a real stem
# (e.g. "tradition*" -> traditional). Multi-word/hyphenated phrases match literally.
# Deliberately excludes generic setting vocabulary (council, government, corporation,
# market, trade, device, merchant, hierarchy...) that's core sci-fi furniture, not a
# texture signal — those would flag most of the corpus and defeat the point of a filter.
