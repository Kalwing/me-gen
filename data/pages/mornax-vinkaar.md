**Location:** Andromeda / Heleus Cluster / Anasa System /  **Fourth planet**

## Description

A turian exile attempted to found a trading post on one of this gas giant's minuscule moons. The project ended in disaster. "Mornax Vinkaar" is a turian phrase for "bad mistake."
